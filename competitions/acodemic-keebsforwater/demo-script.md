# Demo script

Run this against the local app. Do not use the public Vercel URL for the new community flow. On 24 November 2026 that deployment still rejected session creation.

Local address used for the tests: http://127.0.0.1:3010

1. Open the landing page. Read the headline and the line that this is not emergency interpretation and does not decipher an unknown language.
2. Start community access. Choose Community facilitator, tick the confirmation, and create the session.
3. Show the session code and the QR code. On a second browser profile, open `/start?code=` and join as Participant. Say that the role guides the steps and does not decide meaning.
4. Choose "Asking for an everyday item". Show a cup, or say that the cup was shown, then press "I showed it".
5. On the facilitator screen, enter "water" and lock it. On the participant screen, reload and show that "water" is not visible. Enter "cup" and lock it.
6. Reload both screens. Both readings are now visible. Say that agreement is a session record, not proof of a word.
7. Press "The object and the action are both possible", then "Suggest a check". Read the empty-container, liquid, and drinking outcomes, and the line that this is not a measured information gain.
8. Approve the check. Point out that nothing was marked session-verified.
9. Open the board only if the session already has concept cards. Arrange them, show the row, and record "Ask for clarification". The order note says it is not a grammar and not a translation.
10. Open Record. The counts match this session. Download the Markdown summary and read the sentence that a prototype does not show a reduction in inequality.
11. If the session was created for the demo, delete it from Discovery by typing its code. Leave SHORE-1001 in place and say that it is an illustrative sample.

If the AI disclosure says demo mode, say so. Do not describe the suggested check as a model's reading of a photograph unless an API key is configured and a file was actually sent.
